# Changelog

## 0.1.0

- Klient Banking API: sesje, rachunki, historia jednego/wielu rachunków i dodatkowe uwierzytelnianie.
- Izolacja ciasteczek, walidacja, timeouty, anulowanie i obsługa błędów bez sekretów.
- Moduł NestJS z `forRoot`, `forRootAsync` i wstrzykiwanym klientem.
- Eksporty ESM/CommonJS, deklaracje TypeScript, testy offline i opt-in test API.
